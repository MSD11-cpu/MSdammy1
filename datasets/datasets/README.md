Sample Annotation Dataset

Overview

This folder contains a sample dataset demonstrating how labeled image annotation data can be structured for AI training workflows.

Dataset Fields

- "image_id" — Identifier for the image.
- "object" — The identified object.
- "label" — Classification label assigned to the object.
- "x_min" — Left boundary of the bounding box.
- "y_min" — Top boundary of the bounding box.
- "x_max" — Right boundary of the bounding box.
- "y_max" — Bottom boundary of the bounding box.
- "quality_check" — Annotation verification status.

Purpose

The dataset demonstrates basic object detection annotation, classification, bounding-box labeling, and quality verification.

Note

This is a sample portfolio dataset created for demonstration purposes. It does not contain confidential client or personal data.
